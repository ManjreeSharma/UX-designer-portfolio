# Affinity Mapping

**Objective**

After conducting user interviews and usability testing, observations were grouped into common themes to identify recurring usability issues and prioritize design opportunities.

<img width="1536" height="1024" alt="ChatGPT Image Aug 7, 2026, 09_44_45 PM" src="https://github.com/user-attachments/assets/e6348ae7-18b4-4996-ae6f-e439f6cd884b" />

| Theme                     | Insight                                                          |
| ------------------------- | ---------------------------------------------------------------- |
| Authentication Complexity | Users struggled with multi-step login and MFA.                   |
| Administrative Efficiency | IT administrators needed fewer clicks and faster workflows.      |
| Navigation                | Important actions were difficult to locate.                      |
| Accessibility             | Keyboard and screen reader support required improvement.         |
| Guidance                  | Users wanted clearer instructions and better feedback.           |
| Security & Confidence     | Users preferred secure workflows that were simple to understand. |
