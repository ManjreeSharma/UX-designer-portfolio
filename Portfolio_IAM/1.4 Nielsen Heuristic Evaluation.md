# Nielsen Heuristic Evaluation
**Objective** 

Evaluate the existing IAM authentication workflow using Jakob Nielsen's 10 Usability Heuristics to identify usability issues and define design opportunities.
| Nielsen Heuristic                                           | Observation                                                                                                                           | Severity | Design Recommendation                                                               |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | -------- | ----------------------------------------------------------------------------------- |
| **1. Visibility of System Status**                          | Users received little feedback during login and MFA verification, making it unclear whether the process was progressing successfully. | High     | Add progress indicators, loading states, and success/error confirmations.           |
| **2. Match Between System & Real World**                    | Security terminology such as "Authenticator App" and "OTP" was unfamiliar to first-time users.                                        | Medium   | Use plain language with brief explanations and onboarding guidance.                 |
| **3. User Control & Freedom**                               | Users could not easily cancel, go back, or restart the MFA setup process.                                                             | High     | Provide Back, Cancel, Retry, and Skip (where appropriate) options.                  |
| **4. Consistency & Standards**                              | Labels, button styles, and navigation patterns varied across authentication screens.                                                  | Medium   | Apply a consistent design system for forms, buttons, icons, and navigation.         |
| **5. Error Prevention**                                     | Password requirements were shown only after form submission, leading to repeated validation errors.                                   | High     | Display password rules upfront with real-time validation and inline feedback.       |
| **6. Recognition Rather Than Recall**                       | Users had to remember password rules and MFA setup steps from previous screens.                                                       | High     | Keep instructions visible throughout the process and provide contextual guidance.   |
| **7. Flexibility & Efficiency of Use**                      | IT administrators needed multiple clicks to create users, assign roles, and reset passwords.                                          | High     | Introduce bulk actions, search filters, shortcuts, and reusable templates.          |
| **8. Aesthetic & Minimalist Design**                        | Dashboards displayed excessive information, making important actions difficult to locate.                                             | Medium   | Simplify layouts, reduce visual clutter, and improve visual hierarchy.              |
| **9. Help Users Recognize, Diagnose & Recover from Errors** | Error messages lacked actionable guidance, leaving users unsure how to proceed.                                                       | High     | Provide descriptive error messages with suggested recovery steps.                   |
| **10. Help & Documentation**                                | Help resources were difficult to find during authentication and account recovery.                                                     | Medium   | Include contextual help links, FAQs, and guided onboarding throughout the workflow. |
