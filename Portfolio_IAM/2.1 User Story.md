# User Stories
## Persona 1 – Swati (New Employee)

As a new employee,
I want to log in and complete MFA setup without confusion,
So that I can securely access company applications on my first day.

## Persona 2 – Priya (Visually Impaired Business Analyst)

As a visually impaired employee,
I want to complete authentication using a screen reader and keyboard,
So that I can access enterprise applications independently.

## Persona 3 – Rajesh (IT Administrator)

As an IT Administrator,
I want to quickly manage users, assign permissions, and reset passwords,
So that I can reduce manual effort while maintaining organizational security.

## Persona 4 – Amit (Department Manager)

As a Department Manager,
I want to review and approve employee access requests quickly,
So that my team receives the required permissions without unnecessary delays.
