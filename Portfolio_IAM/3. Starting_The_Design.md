# 2. Paper Wireframes

**Goals**
1. Simplify the enterprise login experience.
2. Reduce cognitive load during authentication.
3. Improve first-time MFA setup.
4. Minimize password recovery effort.
5. Ensure WCAG 2.2 AA accessibility.
6. Create a consistent experience across desktop and mobile.
   
**Thought Process**
1. Started by exploring multiple layout variations.
2. Prioritized the most frequently used actions.
3. Reduced unnecessary steps and visual clutter.
4. Improved information hierarchy and navigation.
5. Added clear labels, guidance, and error prevention.
6. Designed with keyboard navigation and screen readers in mind.
7. Iterated based on usability principles and accessibility best practices.

# Usability Studies
To evaluate the redesigned Identity & Access Management (IAM) platform, two rounds of moderated usability testing were conducted with employees, IT administrators, managers, and accessibility users. Participants completed key authentication and access management tasks while feedback, task completion time, errors, and usability issues were recorded. The findings informed iterative design improvements.

<img width="1573" height="462" alt="image" src="https://github.com/user-attachments/assets/b683a797-028f-4c39-959d-8d212355da24" />

**Key Outcome**

The redesigned experience reduced task completion time, increased user confidence, improved accessibility, and minimized the need for IT support while creating a more efficient authentication and access management workflow.
