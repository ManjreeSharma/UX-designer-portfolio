# User Flow
The user flow illustrates the employee authentication journey, highlighting key actions, screens, and decision points to streamline login, improve usability, and ensure a secure, accessible experience.

**Legend**

**Action** – User actions to complete a task

**Screen** – Pages or screens the user interacts with

**Decision** – Points where the user makes a choice

**Solid Arrow** – Forward navigation

**Dotted Arrow** – Return to a previous step after an error
